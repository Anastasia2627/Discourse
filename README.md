# DISCOURSE

Сайт маркетингової агенції DISCOURSE на основі наданого візуального референсу.

## Запуск

Без збірки та залежностей: відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python3 -m http.server 4173
```

Потім відкрийте http://localhost:4173.

Щоб опублікувати через GitHub Pages, відкрийте **Settings → Pages → Deploy from a branch → main / (root)**. Шляхи до ресурсів відносні та працюють під адресою репозиторію.

## Файли

- `index.html` — семантична структура сторінки.
- `styles.css` — фон кожної секції: градієнти, підсвічування, скло, текстура, адаптивність і анімації.
- `main.js` — 3D-паралакс, інтерактивні картки, копіювання короткого брифу.
- `public/assets/logo.svg` — оригінальний логотип, який завантажила власниця.

Форма поки **не імітує відправлення**: без підтвердженого контакту та серверної інтеграції можна сформувати й скопіювати запит. Підключіть контактний канал окремо.

Рух зменшується для відвідувачів з налаштуванням `prefers-reduced-motion`; елементи доступні з клавіатури.
