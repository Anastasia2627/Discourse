# DISCOURSE — материалы для сайта

Сюда загружаем оригинальные визуальные материалы агентства.

## Что прислать

- `logo.svg` — логотип DISCOURSE на прозрачном фоне (лучше SVG из Figma/Illustrator). Если есть тёмная и светлая версии, загрузи `logo-dark.svg` и `logo-light.svg` вместо одного файла.
- `case-01.webp`, `case-02.webp` и т. д. — обложки **реальных** проектов для карточек портфолио. Подойдут экспортированные изображения, скриншоты или качественные мокапы.
- `team-01.webp` и т. д. — реальные фотографии команды, только если захотим использовать их в разделе «О нас».

## Не требуется экспортировать картинками

- Синие градиенты, свечение, размытия и объёмные световые пятна.
- Полупрозрачная стеклянная панель.
- Скруглённые карточки, границы, кнопки, текст.
- Плавные переходы/волны между секциями.

Это построим кодом (CSS/SVG/WebGL), чтобы всё адаптировалось под экран и анимировалось. Референс-скриншот не нужно нарезать на части.

**Совет:** изображения для портфолио экспортировать в WebP без лишних полей, логотип — в SVG. Не добавлять выдуманные кейсы или показатели.
